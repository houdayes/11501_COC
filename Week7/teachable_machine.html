Teachable Machine

專為六年級同學設計的 AI 機器學習初體驗，讓我們一起教電腦辨識物品！

1 認識 Teachable Machine

Teachable Machine 是一個由 Google 開發的超酷網站！它讓大家可以在網頁上直接建立自己的「機器學習」模型，而且完全不需要寫程式喔！

你可以把 Teachable Machine 想像成一個非常聰明但剛出生的寶寶。透過給它看很多的照片、聽很多聲音或是看不同的動作，你可以「教」它認識這個世界。這就像是我們學習分辨蘋果和香蕉一樣。

機器的學習三步驟：

  • 收集資料： 給電腦看很多照片 (例如：很多可回收物品的照片)。
  • 進行訓練： 電腦會自己尋找這些照片的共通特徵，努力學習。
  • 預測評估： 拿一張新照片考考電腦，看它猜得對不對！

今天，我們將要使用 Teachable Machine 的「圖片專案 (Image Project)」，來教電腦認識我們的圖卡！

3 上課操作順序

1

準備階段

  • (1) 詳讀上方「認識 Teachable Machine」的介紹。
  • (2) 負責同學借用 網路攝影機 (單數號)。
  • (3) 負責同學借用 圖卡 (特定雙數號)。
  • (4) 將網路攝影機接上電腦的 USB 插槽。
2

網頁操作階段

  • (5-1) 開啟 Teachable Machine 網站。
    ⚠️ 注意：開啟網站時，請務必點選「允許」使用網路攝影機！
    然後點選畫面上的 「Get Started」 按鈕。
  • (5-2) 選擇 「圖片專案 (Image Project)」 後，點選 「標準圖像模型 (Standard image model)」。
  • (5-3) 編輯類別名稱：將預設的「Class 1」更改為 「可回收」。
  • (5-4) 點選 「Webcam」 按鈕，準備拍照！
    💡 技巧：使用網路攝影機拍攝各物品圖卡時，請讓每個物品「佔滿」網路攝影機的畫面，這樣電腦才看得清楚喔！
3

收拾與歸還

  • (6) 收好圖卡。
  • (7) 收好網路攝影機 (請將線整齊捲好)。
  • (8) 歸還網路攝影機：請依序放回櫃子上 (如上方 webcam-03.png 所示，黃色標籤朝外)。
  • (9) 歸還圖卡：圖卡依序放入透明塑膠夾內，交回教師電腦旁的桌子上。
